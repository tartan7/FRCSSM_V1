# テストスイート

このディレクトリには、リファクタリングされたアプリケーションの包括的なテストスイートが含まれています。

## テストファイル構成

### 基本テスト
- `test_framework.py` - カスタムテストフレームワーク
- `test_models.py` - データモデルのテスト
- `test_services.py` - サービスクラスのテスト
- `test_utils.py` - ユーティリティクラスのテスト

### イベント処理テスト
- `test_event_handling.py` - イベント処理のテスト
- `test_functional_operations.py` - 機能操作のテスト
- `test_interactive_events.py` - インタラクティブイベントのテスト

### テストランナー
- `run_comprehensive_tests.py` - 包括的テストランナー
- `run_all_tests.py` - 全テスト実行
- `simple_test_runner.py` - シンプルテストランナー

## テストの実行方法

### 1. 包括的テストの実行

```bash
# すべてのテストを実行
python run_comprehensive_tests.py --mode all

# クイックテスト（基本的なテストのみ）
python run_comprehensive_tests.py --mode quick

# UIテスト（ウィンドウ作成とレイアウトテスト）
python run_comprehensive_tests.py --mode ui
```

### 2. 個別テストの実行

```bash
# データモデルのテスト
python test_models.py

# サービスのテスト
python test_services.py

# ユーティリティのテスト
python test_utils.py

# イベント処理のテスト
python test_event_handling.py

# 機能操作のテスト
python test_functional_operations.py

# インタラクティブイベントのテスト
python test_interactive_events.py
```

### 3. シンプルテストランナーの実行

```bash
# 全テストを順次実行
python simple_test_runner.py
```

## テスト結果の解釈

### 成功の場合
```
✅ テスト名 完了: X 成功, 0 失敗
```

### 失敗の場合
```
❌ テスト名 完了: X 成功, Y 失敗
```

### エラーの場合
```
❌ テスト名 実行中にエラー: エラーメッセージ
```

## テストの追加

新しいテストを追加する場合は、以下の手順に従ってください：

1. 適切なテストファイルに新しいテスト関数を追加
2. テスト関数は `test_` で始まる名前にする
3. テスト関数は `True` を返す（成功）か `False` を返す（失敗）
4. アサーション関数（`assert_true`, `assert_equal` など）を使用
5. エラーハンドリングを適切に実装

## 注意事項

- テストは独立して実行できるように設計されています
- 外部依存（Excelファイル、データベースなど）はモックを使用
- ウィンドウの作成と破棄は適切に管理されています
- エラーが発生した場合は詳細な情報が表示されます

## トラブルシューティング

### インポートエラーが発生する場合
- プロジェクトのルートディレクトリから実行していることを確認
- Pythonパスが正しく設定されていることを確認

### ウィンドウが表示されない場合
- TkEasyGUIが正しくインストールされていることを確認
- ディスプレイ環境が適切に設定されていることを確認

### テストが失敗する場合
- エラーメッセージを確認
- 関連するファイルが存在することを確認
- 依存関係が正しくインストールされていることを確認
