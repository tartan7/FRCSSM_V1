# 記録書簡易システム (FRCSSM) v2.0

## 概要

記録書簡易システムは、葬儀関連の記録管理を効率化するためのPythonアプリケーションです。TkEasyGUIを使用したGUIアプリケーションとして開発され、MVCパターンに基づいてリファクタリングされています。

## 主な機能

### データ管理
- **香典入力**: 香典の記録と管理
- **供花料入力**: 供花料の記録と管理
- **弔辞弔電入力**: 弔辞と弔電の記録
- **供物入力**: 供物の記録と管理
- **焼香順入力**: 焼香順の記録
- **基本情報入力**: 葬儀の基本情報管理
- **施工状況入力**: 施工状況の記録

### 集計・出力機能
- **通夜集計**: 通夜関連の集計処理
- **葬儀集計**: 葬儀関連の集計処理
- **清書出力**: 清書データの出力
- **CD作成**: データのCD化

### 管理機能
- **フォルダ作成・設定**: プロジェクトフォルダの管理
- **詳細設定**: アプリケーション設定
- **領収書チェック**: 領収書の確認

## アーキテクチャ

### MVCパターン
```
Model層: データモデル（KodenModel, FlowerModel, etc.）
View層: GUIレイアウト（gui01.py, gui02.py, etc.）
Controller層: コントローラー（MainController, KodenController, etc.）
```

### サービス層
```
DataService: データアクセスの統一管理
ExcelService: Excel操作の専門化
FileService: ファイル操作の専門化
ValidationService: データ検証の専門化
```

### ユーティリティ層
```
LayoutManager: GUIレイアウトの管理
PerformanceOptimizer: パフォーマンス最適化
Logger: ログ管理
ErrorHandler: エラーハンドリング
```

## インストール

### 必要な環境
- Python 3.8以上
- Windows 10/11
- Microsoft Excel

### 必要なライブラリ
```bash
pip install TkEasyGUI
pip install xlwings
pip install pykakasi
pip install psutil
```

### インストール手順
1. リポジトリをクローンまたはダウンロード
2. 必要なライブラリをインストール
3. `src/main_optimized.py`を実行

## 使用方法

### 基本的な使い方
1. アプリケーションを起動
2. 基本情報・施工情報入力を選択
3. 必要な情報を入力
4. 各機能（香典入力、供花料入力など）を使用
5. 集計処理を実行
6. 清書出力またはCD作成

### ファイル構成
```
FRCSSM_V1/
├── src/
│   ├── controllers/          # コントローラー層
│   ├── models/              # データモデル層
│   ├── services/            # サービス層
│   ├── views/               # ビュー層
│   ├── utils/               # ユーティリティ
│   ├── tests/               # テスト
│   └── main_optimized.py    # メインアプリケーション
├── logs/                    # ログファイル
└── README.md               # このファイル
```

## トラブルシューティング

### よくある問題

#### 1. Excelファイルが開けない
- Excelがインストールされているか確認
- ファイルのパスが正しいか確認
- ファイルが他のアプリケーションで開かれていないか確認

#### 2. メモリ不足エラー
- アプリケーションを再起動
- 他のアプリケーションを終了
- システムのメモリを増設

#### 3. レイアウトが崩れる
- ディスプレイの解像度を確認
- フォントサイズを調整
- ウィンドウサイズを変更

### ログの確認方法
1. `logs`フォルダを開く
2. 該当する日付のログファイルを確認
3. エラーメッセージを確認
4. 必要に応じて開発者に連絡
